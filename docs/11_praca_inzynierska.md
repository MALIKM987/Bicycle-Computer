# Powiązanie z pracą inżynierską

## Cel dokumentu

Ten plik służy do powiązania repozytorium z opisem pracy inżynierskiej. Po dodaniu PDF pracy można uzupełnić tutaj odwołania do konkretnych rozdziałów, rysunków i tabel.

## Aktualny status

W tej wersji dokumentacji nie wykorzystano jeszcze treści PDF pracy inżynierskiej, ponieważ plik PDF nie został dołączony do rozmowy. Po dodaniu PDF można uzupełnić dokumentację o:

- zgodność nazewnictwa z pracą,
- parametry sprzętowe z pracy,
- opis bloków zgodny z rozdziałem projektowym,
- wyniki testów z rozdziału walidacji,
- linki do rysunków, tabel i schematów.

## Proponowane mapowanie repozytorium na rozdziały pracy

| Obszar repozytorium | Odpowiednik w pracy |
|---|---|
| README | streszczenie projektu i instrukcja uruchomienia |
| docs/01_architektura.md | architektura systemu |
| docs/02_sprzet.md | opis części sprzętowej |
| docs/03_firmware.md | opis oprogramowania |
| docs/04_algorytmy.md | algorytmy pomiarowe i obliczeniowe |
| docs/08_testy_walidacja.md | testy i walidacja |

## Co warto dodać po analizie PDF

- numer i tytuł pracy,
- krótki opis celu pracy,
- listę zastosowanych elementów,
- parametry konfiguracyjne,
- wyniki pomiarów,
- zdjęcia prototypu,
- schemat blokowy zgodny z pracą,
- informację, które elementy repozytorium odpowiadają konkretnym rozdziałom.
