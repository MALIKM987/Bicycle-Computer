# Opis projektu do portfolio

## Krótki opis

Komputer rowerowy oparty o STM32, integrujący czujnik Halla, BME280, IMU, OLED i UART. Projekt realizuje pomiar prędkości, dystansu, parametrów środowiskowych, wysokości, nachylenia, VAM oraz orientacyjne szacowanie mocy rowerzysty.

## Opis do CV

Zaprojektowałem i zaimplementowałem prototyp komputera rowerowego na mikrokontrolerze STM32. Projekt obejmuje obsługę czujnika Halla do pomiaru prędkości i dystansu, integrację czujników I2C, obliczanie parametrów jazdy, interfejs OLED oraz diagnostykę UART/CSV.

## Propozycja opisu na GitHub

STM32-based bicycle computer prototype with Hall sensor speed measurement, BME280 environmental sensing, IMU orientation data, OLED user interface and UART/CSV diagnostics. Documentation and firmware architecture prepared for further development and custom PCB migration.
